cliente envia mensagem → IA principal interpreta a intenção e encaminha para setor(node) responsável → node responsável processa a informação e retorna para IA (node) principal → IA principal retoma a conversa com cliente com as informações processadas para cliente.

🧠 Modelo Mental Correto (Arquitetura Profissional)

Você descreveu:

Cliente → IA principal → setor → volta para IA → responde cliente

Isso é o que chamamos de Arquitetura Orquestrada por Agente Supervisor.

Em termos profissionais:

IA principal = Orquestrador

Nodes/setores = Workers / Ferramentas

Google Calendar / Sheets = Camada de Persistência

Webhook/Telegram = Camada de Entrada
